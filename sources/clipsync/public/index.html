Unlock server settings

Use the app password shown by Umbrel. Your devices only need a one-time pairing code.

Connection

Give ClipSync its own HTTPS port. Your other apps, HTTP services, and DNS address records stay unchanged.

Forward only TCP 39443 on your router to this machine’s port 39443. Use the full address, including the port, in both apps.

Scope the token to your domain’s zone. Certificate renewal uses temporary _acme-challenge TXT records, not ports 80 or 443. Keep the hostname DNS-only for a direct connection on this port. Leave the token blank to keep the saved token or use an existing HTTPS reverse proxy.

Pair a device

In the Android or Mac app, choose Your server. Enter the server address and a fresh code for each device.

Paired devices

    Removing a device immediately disconnects it and invalidates its credentials. Clipboard contents never appear in this dashboard.
